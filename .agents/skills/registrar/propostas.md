Read this when the user says a proposal or a quote was sent, won or lost ("enviei a proposta", "mandei o orçamento", "a proposta fechou", "perdemos a proposta"), or says "resolvido" about a proposal line. The core (`SKILL.md`, in this folder) still holds: its line formats, its write flow (re-read before writing, the step 7 reply), its undo rules and what never goes in.

## Proposals: Sent, Won, Lost
One line per proposal that is out with a client, in the waiting format that already exists, in `Memoria/04_Pessoas_Pendencias.md`. This is not a sales funnel: no stages, no contact history.
- **Sent** ("enviei a proposta para a Clínica Vértice", "mandei o orçamento de R$ 2.500 pro João") → under "Pendências Ativas":
  `- ⏳ **[AGUARDANDO: Cliente]** Resposta da proposta — [o que foi proposto] — R$ [valor] — vale até YYYY-MM-DD. *(desde YYYY-MM-DD)*`
  - `desde` is the day it was sent: today, or the day the user says ("ontem", "na segunda"), computed with the date tool.
  - `R$ [valor]` and `vale até` are optional: fill them from what the user said or from that client's newest file in `Ativos/Propostas/`, and leave out what you do not know — never ask for them, never invent them.
  - The missing-deadline question (the core's Write Flow, step 4) does not apply: never ask for a deadline here.
  - If that client already has a `Resposta da proposta` line for the same thing (same service, or the user says it was revised or resent), update it in place instead of adding a second one; a proposal for something else is a second line.
  - Generating a proposal is not sending it: write this line only when the user says it was sent — and only this line: no person line, no project.
  - The first time in a conversation, add one line between the ✅ and the "desfaz" hint: *"Vou mostrar no radar há quantos dias está sem resposta. Quando tiver, diga "a proposta fechou" ou "perdemos a proposta"."*
- **Won** ("a proposta fechou", "o João fechou", "aprovaram o orçamento") → move the line to "Pendências Resolvidas" as `- ✅ **[YYYY-MM-DD]** Proposta fechada — [Cliente] — [o que foi proposto] — R$ [valor].` Then ONE line after the ✅: *"Quer que eu abra o projeto?"* — or, when `Memoria/03_Projetos.md` already has a project for that client, *"Quer que eu atualize o projeto [nome]?"* — and change nothing in the projects or in the quarterly goal without a yes.
- **Lost** ("perdemos a proposta", "o João não fechou", "desistiram") → move the line to "Pendências Resolvidas" as `- 🚫 **[YYYY-MM-DD]** Proposta perdida — [Cliente] — [o que foi proposto] — R$ [valor] — motivo: [motivo].` The reason is what improves the next proposal: keep it in the user's own words. When the user gave none, write the line without `— motivo: …` and add ONE line after the ✅: *"Sabe por que não fechou? Se me contar, guardo o motivo para as próximas propostas."* If the answer comes, add it to that same line and show `✏️ Antes: ... → Agora: ...`; if it does not, never ask again and never guess a reason.
- **Which line.** Close the waiting line that names that client. A waiting line about a proposal or a quote written in another form (by hand or by an older version, e.g. `**[AGUARDANDO]** Resposta do orçamento do João`) is closed the same way. If no waiting line matches, write the `Proposta fechada` / `Proposta perdida` line straight into "Pendências Resolvidas". If two open proposals could be the one, ask which; if the user named no client and no waiting line tells who, ask *"De qual cliente?"* — never guess it. Other waiting lines about the same client (a contract to send, a file to receive) are not touched.
- "Resolvido", said about a proposal line, does not tell the outcome: ask *"Fechou ou não fechou?"* in one line.
- A question ("a Vértice já respondeu a proposta?") records nothing.
